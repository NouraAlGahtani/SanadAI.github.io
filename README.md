# SANAD AI — Promotional Website

Static, responsive showcase for SANAD AI | سند. This is **not** the Flask Mission Control application and the scenario selector does not execute incident response.

## Preview

```bash
python3 -m http.server 8000
```

Visit http://localhost:8000. The `assets/falcon.png` logo is included.

## What it shows

- Five synthetic incident scenarios and safety-governed recovery outcomes
- Adaptive next-sample telemetry forecasting with verified feedback calibration
- Controlled synthetic validation: 35 passing tests, 80 independent test sequences, 98.75% adaptive warning accuracy, and 57.1% lower MAE
- Explicit limits: no production integration; no demonstrated improvement in Qwen3 recovery decisions due to memory

## Publishing

Publish the contents of this folder to GitHub Pages, Netlify, or Vercel. No API keys or build step required. The GitHub button currently links to the creator profile, not a project repository.
